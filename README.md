# 黎明祭 モバイルオーダー

注文はすべて Google スプレッドシートの「注文」シートにリアルタイムで1行ずつ入ります。
メニュー・在庫・売り切れ・無料の杯数などは「メニュー」「設定」シートで変えられます。

- `index.html` お客さん用（QRコードで開いてもらう）
- `staff.html` スタッフ用（厨房・受け渡し・店頭で注文・管理）
- `gas/Code.gs` スプレッドシート側のプログラム

`js/config.js` の `API_URL` が `null` のあいだはデモモード（ブラウザ内だけで動く）。

## 本番にする手順

1. 新しいスプレッドシートを作る → 拡張機能 → Apps Script → `gas/Code.gs` の中身を貼って保存
2. 関数 `setup` を選んで実行（初回は権限の許可が出る）→ 「設定」「メニュー」「注文」シートができる
3. デプロイ → 新しいデプロイ → 種類「ウェブアプリ」、実行ユーザー「自分」、アクセス「全員」→ 出てきたURLを `js/config.js` の `API_URL` に貼る
4. Google Cloud Console（https://console.cloud.google.com）→ APIとサービス → 認証情報 → OAuth クライアントID（ウェブアプリケーション）を作る
   - 承認済みの JavaScript 生成元に、サイトを置くURL（例 `https://xxxx.github.io`）を入れる
   - できたクライアントIDを `js/config.js` の `GOOGLE_CLIENT_ID` と「設定」シートの「GoogleクライアントID」に入れる
5. 「設定」シートの「スタッフ」にスタッフのGmailを入れる
6. このフォルダ（gas と README 以外）を GitHub Pages などに置き、そのURLをQRコードにする

## 当日の使い方
- 「設定」の「日」を 1 / 2 にし、「受付」にチェックを入れると注文できるようになる（スタッフ画面の「管理」からも変えられる）
- 「メニュー」の「用意した数」を入れると、残りが自動で減り、0で売り切れになる
- 「注文」シートの「状態」を直接変えてもよい（受付 → 作成中 → できあがり → 受け渡し済み）
